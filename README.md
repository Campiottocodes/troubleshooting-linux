# 🧠 Troubleshooting Linux

Repositório dedicado a estudos práticos de troubleshooting em ambientes Linux, com foco em análise técnica, diagnóstico e resolução de incidentes.

Este repositório funciona como um **playbook operacional**, reunindo casos reais documentados de forma estruturada.

---

## 🎯 Objetivo

Desenvolver habilidades práticas em:

- Troubleshooting em Linux
- Análise de problemas em rede e serviços
- Interpretação de logs e comandos
- Construção de documentação técnica clara e reutilizável

---

## 📂 Estrutura

Os casos estão organizados por categoria:

- [NTP](./ntp/)
- (em breve: DNS, Rede, Disco, CPU...)

---

## 📘 Como usar

Cada diretório contém um playbook com:

- Sintoma
- Diagnóstico
- Testes realizados
- Causa raiz
- Ação corretiva
- Validação

---

## 🚀 Filosofia

Este repositório segue um padrão:

> Diagnosticar → Validar → Corrigir → Confirmar
